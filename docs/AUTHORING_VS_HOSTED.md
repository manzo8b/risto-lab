# Authoring e sito ospitato

Il sito GitHub Pages è pubblico e di sola lettura per il catalogo. Non può modificare il repository o caricare permanentemente file dal browser. I piani di lezione sono invece dati locali del browser.

Nel checkout originale, `npm run dev:authoring` apre su porta 4325 la copia locale recuperabile creata prima della conversione. È una copia di lavoro separata e ignorata da Git; la precedente applicazione di importazione/revisione è conservata integralmente, con il suo lockfile. I dati operativi originali non vengono migrati né sovrascritti dalla conversione. Un clone GitHub nuovo non contiene questo ambiente, gli originali o i dati locali.

Per preparare nuovi contenuti: lavorare nell'ambiente locale, chiarire proprietà/licenza e privacy, completare la revisione didattica, trasferire nel catalogo pubblico soltanto i campi e gli asset approvati, eseguire validazione/build/gate, quindi pubblicare una nuova versione. Non copiare provenienza con percorsi del computer, backup, documenti personali o l'archivio completo.

Le route informative online spiegano questa distinzione e non espongono controlli di upload non funzionanti. La gestione contenuti non appare nella navigazione quotidiana.
