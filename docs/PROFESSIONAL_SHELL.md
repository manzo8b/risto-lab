# Instructor Hub — Struttura professionale

Il layout condiviso Instructor.astro usa un’intestazione bianca con identità RISTO—LAB, ricerca, AI e un solo profilo alimentato da currentInstructor. Nessuna autenticazione o badge di ambiente. La sidebar mantiene Home, Programma, Lezioni, Biblioteca, Cerca, RISTO-LAB AI, Aula. Normativa, Raccolte, Sicurezza Alimentare e Media restano secondari.

InstructorFooter chiude le pagine normali con identità, ambito professionale, copyright e tre collegamenti reali: sito RISTO-LAB, GitHub e note sul progetto. Nessun link provvisorio. Console e Vista Aula mantengono il layout didattico e non importano il footer.

InstructorBreadcrumbs fornisce percorsi semantici per programma, unità, risorse e preparazione delle lezioni. I vecchi percorsi ridondanti sulle unità e sui materiali sono sostituiti. Ricerca → materiale mantiene un collegamento ai risultati con la parola cercata.

Palette esistente, superfici chiare, focus visibile, target di almeno 44px per le nuove azioni, transizioni 180ms e rispetto di prefers-reduced-motion. A larghezza ridotta, le scorciatoie dell’header cedono alla navigazione principale unica; il profilo resta nell’header. Nessun nuovo sistema di menu.
