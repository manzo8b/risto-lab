# Matrice Allergeni 2.6 — data integrity

Three-column import preserves category and original ingredient text. A recognised explicit proposed-ingredient marker separates proposed from stated source text; unmarked inputs retain unspecified provenance. Header language is a reviewable suggestion, not language detection or translation; explicit language takes precedence. Reports add category, separate source fields and state-1/state-2 code columns; final combined code summary remains last. No allergen auto-confirmation; OSA review and internal-use restrictions unchanged. Existing structured imports and session schema retained. Private menu data is not committed; synthetic 195-row regression only. Reimport the original workbook for old exports that lost category. PDF/Word/Markdown detail reports include metadata and separate code groups. The dictionary itself is not revised; same-allergen alternative expressions remain conservative pending a separate semantic evaluation.
