# Controllo prepubblicazione

Il repository contiene solo applicazione statica, catalogo e asset autorizzati, test e documentazione corrente. Esclusi: ambiente locale di authoring, dati operativi, archivio, backup, provenienza Mac, chiavi .env, dipendenze, dist, log e screenshot temporanei.

Controlli: gate sui candidati Git e loro dimensioni; ricerca di chiavi/token/chiavi private e percorsi utente; audit automatico di tutto dist per payload locali, percorsi assoluti e link alla radice errati; verifica delle route rimosse; nessun nuovo segreto richiesto dalla build. I pattern sono controlli tecnici, non una certificazione esaustiva di assenza di qualunque possibile informazione personale.

Contenuti: dichiarazione esplicita del proprietario registrata nel catalogo pubblico. Le attribuzioni a fonti terze già note non sono state sostituite da una titolarità inventata. Nessun materiale con privacy PRIVATE_ONLY o diritti UNKNOWN viene pubblicato. Le fonti normative mantengono l'indicazione di vigenza non verificata.

Il sito è pubblico. Non è promessa un'area autenticata o riservata. I piani locali non entrano nella build né nel repository; l'utente deve evitarvi dati sensibili.
